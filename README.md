# CursorHelper

**CursorHelper**는 시스템 트레이에 상주하는 트레이 아이콘을 사용하여 마우스 커서 구성표, 간단히 말해 커서 테마를 간단하고 빠르게 전환하는 것을 목표로 하는 편의성 도구입니다.

## 주요 기능
### 1. 구성표 즉시 전환
트레이 아이콘을 우클릭하는 것 만으로 간단하게 시스템에 등록되어 있는 모든 커서 구성표를 확인하고 원클릭으로 전환할 수 있습니다.

### 2. 커서 파일 불러오기
기존 윈도우 제어판의 사용 경험과 크게 다르지 않은 방법으로 커서 아이콘(`.cur` 또는 `.ani` 형식)들을 읽어들이고 구성표로 등록할 수 있습니다. (미리보기를 제공합니다!)

### 3. 자동 할당
파일들이 저장된 폴더, 또는 그 파일들을 담고 있는 ZIP 파일을 입력으로 사용하여 자동 할당을 시도할 수 있습니다. \
다음의 3단계 로직을 통해 커서 역할을 자동으로 할당합니다.
    1. **파일명 일치:** 파일명에 'Arrow', 'Wait' 등의 시스템 키워드가 포함되어 있는지 확인.
    2. **시스템 리소스 대조:** `main.cpl` 리소스에서 추출한 로컬라이즈된 명칭(예: 'Arrow'의 경우 '일반 선택')과 대조.
    3. **사용자 별칭(Alias):** `cursor_aliases.csv`에 정의된 매핑 키워드 확인. (작성법은 [별도 항목](#cursor_aliasescsv) 확인)

### 4. 백업 & 리스토어
현재 구성표를 ZIP 파일로 패키징하여 내보냅니다. \
파일과 구성표 항목을 매개하는 매핑은 `scheme.ini`의 형태로 직렬화되어 ZIP 파일에 함께 패키징됩니다.\
`scheme.ini`가 존재하는 경로 또는 ZIP 파일을 여는 경우 [자동 할당](#3-자동-할당)을 건너뛰고 `scheme.ini`에 정의된 그대로 매핑을 수행해 줍니다.

### 5. 빠른 바로가기
마우스 설정을 직접 방문해야 하는 경우 (예: 구성표 삭제 등), `[제어판]` - `[하드웨어 및 소리]` - `[장치 및 프린터]` - `[마우스]` - `[포인터]` - `[구성표]`를 직접 방문할 필요 없이, `Windows 마우스 설정` 옵션을 통해 바로 해당 항목에 진입할 수 있습니다.

## `cursor_aliases.csv`
- `cursor_aliases.csv`는 없어도 기능에 큰 지장을 주지 않습니다.
- `cursor_aliases.csv`를 내려받아 실행파일 또는 `main.py`가 있는 경로에 배치한 후 실행시 추가적인 aliases가 파일명 인식에 반영됩니다.
- 현재 `cursor_aliases.csv`에는 en_US와 ko_KR에 대한 alias가 적용되어 있습니다. `.cur` 및 `.ani` 파일들의 이름이 이 alias를 따르고 있는 경우 자동 할당이 적용됩니다.
- 작성 규약은 다음과 같습니다:
  1. `UTF-8` 인코딩으로 저장
  2. 첫번째 행은 헤더 행으로, 무시됩니다. 지우거나 훼손하지 않도록 주의하십시오.
  3. 첫번째 열은 시스템 키를 저장합니다. 지우거나 훼손하지 않도록 주의하십시오.
  4. 두번째 행/열부터는 해당 역할로 인식시키고 싶은 파일명 키워드를 자유롭게 작성해 주십시오. `.csv` 포맷을 따르므로 쉼표를 구분자(delimiter)로 사용하니 작성 중에 주의하십시오.

## 설치 및 실행

### 일반 사용자 (실행 파일)

[Releases] 페이지에서 압축파일을 내려받아 압축을 해제하고 `.exe` 파일을 실행하십시오 (별도 설치 과정 없음)

### 개발자 (소스 코드 실행)

본 프로젝트는 **Python 3.12.8** 환경에서 개발되었습니다.

#### **저장소 클론**
```bash
git clone https://github.com/username/CursorHelper.git
cd CursorHelper
```

#### **가상 환경 생성 및 의존성 설치**
```bash
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
```

#### **실행**
```bash
python -m main
```

## Future Works

### 레지스트리 트랜잭션 미보장
- **설명** - 레지스트리 직접 수정을 통해 커서 구성표 변경을 구현하고 있음. Atomicity를 보장하지 않으므로 설정 저장 도중 프로세스가 강제 종료되는 경우 구성표의 일부가 변경되지 않고 누락될 수 있음
- **리스크 및 리스크 수준** - 없거나 낮음 (시스템의 다른 부분에 문제를 끼치지 않음)
- **향후 계획** - 없음 (장기적으로 UWP 설정 앱을 통한 구성표 제어로 전환하여 레지스트리를 직접 수정하는 구조를 벗어날 수는 있지만, 여전히 Atomicity를 보장할 수 없음)

### 레거시 의존성 제거
- **설명** - 다국어 지원이 `main.cpl.mui`에 의존적임
- **리스크** - Microsoft가 레거시 지원을 드롭하는 즉시 '사용자 언어를 사용한 [자동 할당](#3-자동-할당)'이 기능을 정지
- **리스크 수준** - 낮음 (레거시 지원 중단이 빠른 시일 내에 발생하리라 보기 어려움)
- **향후 계획** - 장기적으로 UWP 설정 앱 기반으로 전환할 때 `main.cpl.mui`을 경유하지 않는 다국어 지원 방법을 모색

### Over-complex 구조 탈피
- **설명** - 메인 스레드, GUI 스레드, tray icon 스레드를 분리하는 설계를 통해, 어느 한 프로세스가 hanging되어도 다른 도구까지 모두 freeze되는 상황을 예방코자 함. 목적은 달성되었으나, Python 언어에 대한 이해도 부족으로 `MainThreadDispatcher`라는 불필요한 구현이 도입되었음
- **리스크 및 리스크 수준** - 없거나 낮음 (이점도 일부 존재하는 설계이긴 하나, 비효율을 동반)
- **향후 계획** - `MainThreadDispatcher`를 별도 모듈로 분리하여 이 프로젝트에서 제거.
